# Prompt — Etapa 4: Blueprint app mobile premium (Expo + RN + TS)

> Activar tras Etapa 3 go. Objetivo: especificar (y luego implementar en Etapa 5) una app **extremadamente bonita e intuitiva**, sin errores, en ecosistema Expo moderno.

## Rol
React Native/Expo Senior + UX motion + PSY (seguridad) + A11Y.

## Entregable de esta etapa (blueprint, no necesariamente todo el código)
1. **Information architecture** final (tabs, stacks, deep links).
2. **Design tokens** (color, type, space, radius, elevation, motion).
3. **Librerías recomendadas** (justificadas): p.ej. Reanimated, Gesture Handler, Skia (si aporta), FlashList, expo-image, expo-haptics, expo-notifications, SecureStore, etc. — elegir según necesidad real del repo.
4. **Flujos críticos** wireframe textual: auth demo, onboarding, check-in único, assessment, psicoterapia, biblioteca audio/video, crisis.
5. **Estados**: loading, empty, offline, error, crisis.
6. **Plan de calidad**: Detox/Maestro o checklist manual + typecheck + tests scoring.
7. **ASO**: nombre, subtítulo, keywords ES-CL, capturas a producir.

## Principios de belleza (health, no “AI purple”)
- Una composición por viewport; brand Neuropi hero-level en welcome.
- Tipografía expresiva coherente con `@neuropi/ui`.
- Atmósfera (temas Amanecer/Bosque/Océano/Noche/Alto contraste) sin ruido.
- Motion con propósito (transiciones de onboarding, feedback check-in).
- Cero cards decorativas; cards solo si sostienen interacción.

## Salida
Documento blueprint + lista de tickets Etapa 5 ordenados.  
«Dime continuar…» para implementar.
